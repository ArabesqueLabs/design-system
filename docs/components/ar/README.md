# المكوّنات

> ترجمة لـ[فهرس المكوّنات بالإنجليزية](../README.md). إن اختلفت الترجمة عن الأصل، فالإنجليزية هي المرجع.

وهذه ترجمة لكل المواصفات؛ وتربط بها صفحة العرض حين تكون الصفحة بالعربية، وكل منها صفحة قائمة بذاتها (`button.html`، `ar/button.html`). وحين تتغير مواصفات بالإنجليزية، تتغير ترجمتها معها.

وتراها تعمل في `index.html`، وبـReact، في صفحة لكل منها، في [`examples/`](../../../examples/index.html) (انظر [`docs/react.md`](../../react.md)، بالإنجليزية).

تغطي كل مواصفات: البنية، والأنواع والأحجام، والحالات، ولوحة المفاتيح، وARIA، والكتابة من اليمين إلى اليسار، وما يُفعل وما لا يُفعل، والرموز التي يستخدمها المكوّن (مأخوذة من ملف CSS الخاص به). شاهدها تعمل في `index.html`.
