Arabesque

A design system built by Arabesque Labs (opens in a new tab) to set the standard for every product we make. Written for left-to-right and right-to-left alike, and designed so people get things done in the fewest steps, seeing every consequence.

Browse all elementsAdd it to your project

This tile is our mark. Everything around it follows from the same rule.

What it's for

Four things every product we make should get right, built in so they're right by default.

Accessible, and measured

WCAG 2.2 AA as a floor. Every colour pair is measured at each build, in both themes, and the build fails if one falls short.

Right to left from the start

Every element is written for Arabic as well as English: logical properties, mirrored icons, Arabic type, and Arabic-Indic digits when chosen.

The fewest steps

Actions say what they do, and every consequence shows before, during and after: what else will change, what's saving, what was put back.

Plain CSS, and React

Tokens as custom properties, and plain HTML with classes: no framework, no runtime dependency. The React components write the same markup.

The elements, working together

A few of them, as they'd sit in a product. Try them: they're the real thing.

Questions

Does it work in Arabic?

Yes: every component is written for right to left as well as left to right, and every spec is in Arabic too. How right to left works

Do I need React?

No. The CSS and the small helpers in js/ work on any page; the React components write the same markup.

How is contrast checked?

The build measures every colour pair the system relies on, in both themes, and fails if any falls short.

Can I use it in my own product?

Yes: the code is MIT licensed. The Arabesque and Arabesque Labs logos and marks aren't, so leave them out of your product.
