# Tokens

Generated by `scripts/build.mjs` from [`tokens/tokens.json`](../tokens/tokens.json):
every token, as the custom property the CSS declares (`dist/tokens.css`):
its path in the file, less the layer, prefixed `--al-`.

Use the **semantic** tokens: they name what a value is for, so the themes,
Arabic and contrast stay right in one place. The **primitives** are the
palette they point to; a component uses them only through a role
([principles](principles.md)). A value that's another token is named
without its prefix: `color-cloud-98` is `--al-color-cloud-98`. Where a
mode has its own value, it's beside
the light theme's: dark, under `[data-theme="dark"]` or the system's setting,
and Arabic, under `:lang(ar)`.

## Semantic

### Colour

Roles. Most roles point to a primitive; the exceptions are literal on purpose: translucent colours (washes, line-strong, the backdrop, pattern-line), which are a hue at an alpha that only makes sense for that role, and the tints, which are a fixed palette of their own.
